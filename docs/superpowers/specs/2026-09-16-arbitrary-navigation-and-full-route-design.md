# 任意安全坐标导航与完整跑图设计

## 范围

本次同时修改 `upper_computer` 和实际调试固件 `test/mecanum_jog`。目标是在保留现有安全航点导航与 `route` 命令兼容性的前提下：

1. 在“场地定位”页输入地图内任意安全坐标并移动到该精确坐标；
2. 从启停区执行仅包含底盘运动的完整两轮比赛路线；
3. 在上位机实时显示估计位置、目标和完整跑图阶段。

`yyb_stm32` 只用于核对比赛区域顺序，不复制其中的阻塞式主循环、视觉交互或机械动作。位置继续由命令速度与时间积分估算，IMU只用于航向闭环，不增加编码器、视觉定位、动态避障或自动机械流程。

## 安全约束

- 地图为2400×2400 mm，坐标表示300×300 mm车体中心。
- 车体中心必须位于150～2250 mm边界内。
- 目标点、折点和所有水平/垂直线段都必须通过现有固定设施的扫掠净空检查。
- 规划器只使用现有安全通道图，并以经过净空检查的正交连接段把任意位置接入通道节点。
- 不安全、越界或没有安全连接的目标返回 `ERR NAV:`，不启动电机，也不改变已有有效位置。
- `stop`、`X/x`、`disable`、`!`、心跳超时、CAN故障、IMU故障或运动超时都会停车并使估计位置失效。
- 完整跑图启动前，操作者必须确认机器人位于所选启停区且车头朝地图上方；软件不能验证实际摆放位置。

## 任意坐标规划

### 临时路径图

现有十个安全航点和固定边保持不变。每次 `nav goto` 以当前估计坐标和目标坐标构造临时路径：

1. 对当前点到每个安全节点分别尝试水平优先和垂直优先的正交连接；
2. 对每个安全节点到目标点进行同样尝试；
3. 只有点和完整线段均通过车体净空检查的连接才可作为候选；
4. 对所有入口节点、出口节点及安全图最短路径组合计算总曼哈顿距离；
5. 按总距离、入口节点编号、出口节点编号、连接方向的固定顺序打破平局。

若当前位置或目标恰好在安全节点上，省略对应连接段。生成的实际路线由坐标点组成，删除重复点和连续共线中间点。最大容量覆盖“起点连接折点 + 十个安全节点 + 目标连接折点”。

到达任意目标后保留精确估计坐标。下一次导航从该坐标重新接入安全通道，因此不要求回启停区。任意坐标目标保持进入最终线段前的航向；目标精确匹配原功能航点时，继续使用该航点的预设到达朝向。

### 文本命令

现有接口不变：

```text
nav init 1|2
nav goto <x_mm> <y_mm> [10..120rpm]
nav status
```

`nav goto` 从“只接受十个航点”扩展为接受整数安全坐标。它仍需要一次 `arm` 授权。运行期间继续输出 `NAV POS`，完成输出精确目标的 `NAV DONE`；拒绝使用 `ERR NAV:`。

## 完整跑图

### 路线

复用现有 `routeTemplate` 的16段两轮底盘路线：

1. 启停区出口；
2. 二维码区；
3. 原料区1；
4. 粗加工区1；
5. 暂存区1；
6. 原料区2；
7. 粗加工区2；
8. 暂存区2；
9. 返回原启停区。

中间无视觉等待和机械动作。二维码区向右、原料区向上、粗加工区向下、暂存区向左，返回前恢复向上。入口、中心通道等中间节点不作为作业阶段显示。

### 命令与状态输出

保留现有命令：

```text
route auto 1|2 [10..120rpm]
```

新增结构化输出，但保留原有可读文本回复：

```text
ROUTE POS x=<mm> y=<mm> yaw_cdeg=<cdeg> stage=<name> target_x=<mm> target_y=<mm>
ROUTE STAGE index=<n> name=<name>
ROUTE DONE x=<mm> y=<mm> yaw_cdeg=<cdeg>
ROUTE INVALID reason=<reason>
```

运行期间约每200 ms输出一次 `ROUTE POS`。到达作业区域时输出 `ROUTE STAGE`，但不停车等待机械或视觉。结束时输出 `ROUTE DONE`。任何终止条件输出 `ROUTE INVALID`；已有 `ERR ROUTE:` 继续保留。

完整跑图使用自身所选启停区作为初始估计位置，不要求先执行 `nav init`。启动完整跑图会作废此前的任意导航位置。完整跑图结束后，为避免把命令积分结果当作可靠定位，任意坐标导航仍要求操作者在启停区重新执行 `nav init`。

## 上位机界面

“场地定位”页文本模式保留“安全航点移动”，并新增两个分组。

### 指定坐标移动

- X、Y整数输入框，范围0～2400 mm；固件负责最终净空判定；
- 独立的10～120 RPM速度选择；
- “选择地图当前点击位置”行为不改变，地图点击仍吸附安全航点，避免破坏原操作；
- “移动到坐标”按钮发送现有 `arm → nav goto x y rpm`；
- 未连接、未初始化、正在运动时禁用；
- 目标标记显示输入的精确坐标，固件拒绝后保留输入并显示原因。

### 完整跑图（仅底盘）

- 启停区1/2选择、10～120 RPM速度和“开始完整跑图”按钮；
- 按钮旁持续标注“无视觉、无机械动作、命令积分估计”；
- 点击后弹出一次安全确认，再发送 `arm → route auto zone rpm`；
- 路线运行时禁用两种导航启动按钮，显示当前阶段、估计位置和目标；
- 顶部急停及页面停止继续使用现有停止链路。

`MecanumJogClient` 解析 `ROUTE POS/STAGE/DONE/INVALID` 并提供路线运行状态。断连、停止或错误会清理按钮状态。标准二进制协议页面行为不变。

## 失败处理

- 坐标格式、范围、目标净空、连接净空和无路径分别返回明确 `ERR NAV:` 信息。
- 忙碌时拒绝新的导航或完整跑图，不中断当前动作。
- 完整跑图收到固件错误、停止、急停或断连时立即退出运行状态。
- 上位机不根据本地几何判断代替固件安全检查；本地只做输入范围和按钮门控。
- 固件始终是运动状态与安全拒绝的最终来源。
