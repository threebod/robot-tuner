# 三路舵机滑块与动作记录设计

## 目标

在现有 Qt 上位机和 STM32 调试协议中增加 2、3、4 号舵机的安全角度调试，
并把 HC-05 调试链路修正为 115200 baud。实现参考
`test/mecanum_jog/` 中 UART5、TIM2 CH2–CH4、角度范围和舵机命令语义，
但继续使用上位机现有二进制协议、安全解锁和急停机制。

视觉功能、动作序列保存和动作回放不在本次范围内。

## 麦轮方向按钮校正

现有动作测试页继续保留前进、后退、左移、右移、左转和右转按钮。对照
`test/mecanum_jog/main.c` 的 1–4 号电机方向表，修正四个平移按钮传给
`car_move(vx, vy, w)` 的坐标：

| 按钮 | `vx` | `vy` | `w` |
| --- | ---: | ---: | ---: |
| 前进 | 0 | +80 | 0 |
| 后退 | 0 | -80 | 0 |
| 左移 | -80 | 0 | 0 |
| 右移 | +80 | 0 | 0 |

左转和右转的 `w` 映射保持现状。上位机仍采用速度模式和受限持续时间，不照搬
`mecanum_jog` 的 30 RPM、160 脉冲同步位置模式；本次适配目标是让按钮标签对应的
1–4 号电机方向位与已实测例程一致。

## 串口约定

- USART3 有线调试：115200 8N1。
- UART5 / HC-05 无线调试：115200 8N1。
- Qt 仍只允许一个串口连接；波特率入口只提供 115200，避免选择错误。
- 删除蓝牙 9600 baud 对 IMU 遥测 20 Hz 的特殊限制。两条 115200 链路均使用
  现有 1–50 Hz 范围，设备仍可返回实际采用的频率。

## 协议扩展

在 `TEST_ACTION` 下新增舵机动作变体，使用新的 action 编号，payload 为：

```text
action:u8 servo_id:u8 target_angle_deg:u16
```

- `servo_id` 只允许 2、3、4。
- 舵机 2、3 的目标角度范围为 0–270°。
- 舵机 4 的目标角度范围为 0–360°。
- 数值使用现有小端序。
- 舵机动作属于非幂等物理动作，不进行自动重试。
- 只有当前链路已经 HELLO、动作测试已解锁、未急停时才执行。
- 非法通道、非法角度、未解锁和急停分别沿用现有错误响应。

## STM32 行为

`host_commands` 校验舵机动作并通过新的 callback 下发通道和目标角度。
`host_debug` 将通道 2、3、4 映射到参考例程相同的 TIM2 CH2、CH3、CH4 舵机输出。
角度到 PWM 的换算和更新方式复用已有 `PWM`/舵机接口；不得在串口中断中执行动作，
不得引入阻塞等待。急停、立即停止、看门狗超时和断连 fail-closed 路径必须停止
三路舵机当前插补。

本次只修改 `yyb_stm32` 参考固件的调试入口。它不是当前整车正式固件；真正上车前
仍须通过 `test/yyb_bringup` 和 Keil/实机检查。

## Qt 界面与交互

动作测试页增加三组控件：

- 舵机 2：0–270°；
- 舵机 3：0–270°；
- 舵机 4：0–360°。

每组包含一个水平滑块、一个同步数值框和一个“发送目标角度”按钮。滑块拖动只更新
数值，不发送串口；点击按钮后执行现有确认流程并发送一帧动作，避免拖动时连续发包。
控件继续受连接、握手、动作解锁和急停状态统一禁用。

页面下方增加只读动作记录。每次确认发送舵机动作时追加一条：

```text
舵机 <id> -> <angle>°
```

记录只表示“已发送的目标”，不表示舵机已经到位；不写入文件、不跨程序保存、
不提供编辑或回放。

## 测试与验收

- UI 测试验证三组滑块、数值同步、角度范围、未解锁/急停禁用和记录内容。
- UI/设备测试验证前进、后退、左移、右移按钮生成校正后的 `vx/vy/w`，并对照
  `mecanum_jog` 的四轮方向表做静态合约检查。
- DeviceClient 测试验证三路合法 payload、非法通道/角度拒绝和动作不重试。
- STM32 主机测试验证 payload 校验、callback 参数、链路/解锁/急停门禁。
- 静态测试验证 UART5 与文档均为 115200，旧 9600/20 Hz 分支已移除。
- 运行全量 Qt 构建和 CTest。

自动测试不能替代 Keil `HOST_DEBUG_MODE=1/0` 构建，也不能替代三路舵机限位、
方向、急停和 HC-05 115200 的实机验证。
